# 思想史・章別穴埋め問題集

第1〜11章の穴埋め問題集（全33セット・458問）です。第10・11章は講義ハンドアウトを基に、軽めの補足演習として各3パターン62問を追加しました。

## ファイル構成

- `docs/index.html` — GitHub Pagesで公開する学習ビュアー。HTML単体で動作します。
- `docs/people.html` — 人物名特訓（44人・82関連事項）。「出来事別演習」と「人物一覧」を切り替えられます。人物一覧では現在の説明・元メモ原文（章と行番号）・追加補足を区別して表示します。演習では全問題・直近不正解・苦手・未学習から出題対象を選択できます。事件・訴訟名などに答えが含まれる場合は出題文から除外します。
- `index.html` — ビュアーの複製（リポジトリ内の参照用）。
- `materials/questions.txt` — 問題集（リポジトリ内のみ）。
- `materials/answers.txt` — 解答集（リポジトリ内のみ）。
- `materials/memo_with_supplements.txt` — 第1〜9章の元メモ本文を維持し、第10・11章にハンドアウト準拠の暫定語句メモを追加した版（リポジトリ内のみ）。

### 人物名特訓の学習履歴

- 正誤入力・正解表示・手動判定の結果をカード単位でCookieに保存します（有効期間365日）。
- 「間違えたもののみ」は直近の記録が不正解の問題を選び、正解した問題は次の周回から除外します。
- 「苦手のみ」は2回以上不正解で、直近の連続正解が3回未満の問題、または手動で苦手登録した問題を選びます。手動登録は解除するまで残ります。
- 出題順は章順・ランダム・苦手優先。学習済み件数と状態別の件数も表示します。
- 同じ条件でもう1周する操作で、最新の履歴から対象問題を再抽出します。
- バックアップをJSON形式で保存・復元できます。端末間の自動同期やリマインダーはありません。
- Cookieが無効な環境では保存できないことを画面に表示します。GitHub Pagesや元の問題・解答の内容は変更しません。

## 公開範囲と検索回避

リポジトリの公開範囲はGitHubのSettingsで確認してください。2026年11月1日の確認時点でこのリポジトリはPublicになっています。GitHub Pagesで公開した `docs/index.html` と `docs/people.html` も誰でもURLで閲覧できます。検索エンジンにインデックス登録しないよう `noindex` を設定していますが、非公開アクセス制御ではありません。

`/docs` のみをPages配信に使うため、`/materials` 配下のTXTファイルはPagesから直接配信しません。ただし、リポジトリがPublicの間はGitHubのリポジトリ画面からTXTファイルも閲覧できます。また、ビュアーのHTML/JavaScriptには解答データが含まれており、Pagesの閲覧者も取得できます。

GitHub Pro等、PrivateリポジトリからPagesを公開できる対応プランが必要です。
